# Mahila Bot WebApp

A FastAPI web application that uploads applicant CSV files, runs Selenium automation on the Mahila Shetkari Service portal, and generates acknowledgment numbers as output.

---

## 🚀 Features
- Upload applicant CSV file via web interface
- Automates form filling and tracking using Selenium
- Extracts acknowledgment numbers from the portal
- Generates downloadable output CSV with results
